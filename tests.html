Golf Handicap — Tests

Pins the pure handicap maths in index.html. It loads the real app in a hidden iframe and calls its functions directly — no copies, no build step — so a test can never drift from the code it is testing. Needs http://localhost: file:// iframes are blocked in some browsers — and it only runs there, since that hidden iframe is a real copy of the app, which anywhere else would be your signed-in one.
Run this whenever you touch round1, scoreDifferential, averageLowest, whsIndex/whsSelection, rollingIndex/rollingSelection, normalizeMethod, clampInt/clampNum, applyCaps, courseHandicap, playingHandicap/allowanceById, esrFor, pairNines, courseStats, csvRounds/csvCell, indexHistory, pickUsed, rankLeague, changeOverRounds, syncDecision, buildDemo, buildDemoLeague, encodeShare/decodeShare/buildSharePayload, windowRounds, sanitizeIds or normalizeState.
