Golf Handicap — tests

Pins the pure handicap maths in index.html. It loads the real app in a hidden iframe and calls its functions directly — no copies, no build step — so a test can never drift from the code it is testing. Needs http://localhost: file:// iframes are blocked in some browsers.
Run this whenever you touch round1, scoreDifferential, averageLowest, whsIndex/whsSelection, rollingIndex/rollingSelection, normalizeMethod, applyCaps, courseHandicap, indexHistory, sanitizeIds or normalizeState.
